# dsh-llm-adapters

把 **Loomy（讯飞）** 与 **商汤小浣熊** 的模型接入 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)。

不填 API Key。登录有两种方式，任选其一：

- **浏览器登录（不需要安装桌面客户端）**：点设置页的「打开浏览器登录」，会弹出一个独立的浏览器窗口；你在里面登录官方网页账号，插件检测到登录成功后自动取回凭据并接回设置页。
- **复用桌面客户端登录态**：如果本机已经装并登录了 Loomy 或小浣熊，插件会直接读取它的登录文件。

安装后，模型选择器里出现「Loomy」和「商汤小浣熊」两个分组；设置页与 `dsh-agent-sdk-bridge` 采用同一套结构：登录/额度卡片、模型开关、逐模型上下文窗口、高级设置。

> 非官方插件。两个上游都是客户端私有接口，不是官方开放 API；客户端升级后协议可能变化。

## 浏览器登录是怎么“回调”的

插件不依赖 localhost 回调地址，也不接管你日常使用的浏览器：

1. 用 Chromium 内核浏览器（Edge / Chrome / Brave / Chromium）启动一个**临时用户目录**的新窗口，打开官方登录页。
2. 你在窗口里完成登录。插件通过 DevTools 协议读取该窗口的页面状态、登录接口响应和站点 Cookie，并逐条向模型网关校验。
3. 校验通过后把凭据写入插件自己的存储，关闭临时窗口并删除临时用户目录；设置页在轮询中收到完成状态，自动刷新账号与模型。

同一个窗口同时负责登录与“回调”，因此不需要额外的本地端口，也不会读到你日常浏览器里的 Cookie。浏览器路径找不到时，可以用环境变量 `DSH_LLM_ADAPTERS_BROWSER` 指定可执行文件。

## 功能

- **两种登录**：浏览器登录，或直接复用本机客户端登录态；不需要手动粘贴 Token。
- **模型目录**：读取上游账号实际返回的模型，并显示读图能力、计费倍率、折扣/限免标签与上下文窗口。
- **额度**：Loomy 显示可用/永久/每日积分；小浣熊显示剩余积分。
- **模型开关与上下文窗口**：按模型启用/关闭，并可在不超过上游声明的前提下选择较小的上下文窗口。
- **小浣熊令牌续期**：访问令牌临近过期时自动刷新，并把轮换后的 access/refresh 令牌**原子回写**到提供凭据的地方（插件存储或桌面端 `auth.json`）。不回写会让下一次刷新撞上 `refresh_conflict` 并掉登录。
- **图片输入**：按模型能力把图片转成 data URL；小浣熊使用逐模型实测的识图表，不盲信目录标签。
- **思考内容**：上游返回的 `reasoning_content` 会映射为 DSH 的 reasoning 流。

不包含签到、积分领取或删除桌面应用账号的操作。退出登录只清除插件自己保存的凭据；桌面客户端的登录态不受影响。

## 前置条件

1. DSH 为 `0.2.x` 对应的 Web/Desktop profile。
2. Node.js `^22.19.0 || >=24.0.0`（DSH 自身要求）。
3. 浏览器登录需要本机装有 Chromium 内核浏览器；插件依次查找 Edge、Chrome、Brave、Chromium。
4. 可选：本机已安装并登录 Loomy 或小浣熊桌面端；不装也能用浏览器登录。

插件不启动桌面应用。使用浏览器登录时，凭据由插件自己保存；使用客户端登录态时，插件只读取应用文件（小浣熊令牌刷新会回写该文件）。

## 安装

### 从 npm

```sh
dsh plugin add dsh-llm-adapters
```

### 从源码 / 本地目录

```sh
git clone https://github.com/k1-h2/dsh-llm-adapters.git
cd dsh-llm-adapters
npm install
npm run build
dsh plugin add link:/absolute/path/to/dsh-llm-adapters
```

安装后重启 DSH（含托盘进程），再刷新页面。首次打开设置 → Loomy / 商汤小浣熊，点「打开浏览器登录」完成登录，或让插件读取已登录的客户端。

## 设置页

- **登录卡**：显示登录方式、账号、到期时间与额度；未登录时提供「打开浏览器登录」，登录中可查看状态或取消，插件账号可直接「退出登录」。
- **模型列表**：搜索、只看已启用、全部启用/关闭、逐模型开关与上下文窗口。
- **高级设置**：分组名称、自定义登录态路径、强制识图/纯文本模型 ID、模型别名、默认输出上限。
- **供应商开关**：在插件管理页关闭某个供应商后，它的设置页、模型分组与 provider 路由都会移除；登录态与已保存选择保留。

所有配置写入走 DSH 的 `configForms` 修订栅栏，不经过插件自己的写接口。登录控制与状态走 `POST /api/llm-adapters/account` 与 `GET /api/llm-adapters/account/browser`。

## 凭据与隐私

| 项目 | 浏览器登录 | 桌面客户端登录态 |
| --- | --- | --- |
| 适用 | 不安装客户端时使用 | 本机已安装并登录时自动复用 |
| Loomy 登录 | 在独立窗口登录 `loomy.xunfei.cn` | `%PUBLIC%\Loomy\<安装ID>\userData\auth-session.json` |
| 小浣熊登录 | 在独立窗口登录 `xiaohuanxiong.com` | `~/.box-agent/config/auth.json` |
| 凭据保存位置 | `$DSH_HOME/llm-adapters/accounts.json`（可用 `DSH_LLM_ADAPTERS_HOME` 覆盖），原子写入、仅当前用户可读 | 应用自己的文件，插件只读 |
| 浏览器数据 | 临时用户目录，登录结束后删除；不读取日常浏览器的 Cookie | 不涉及 |
| 密码 | 由你在官方页面输入，插件不接触 | 不涉及 |
| 会话寿命 | Loomy 约 14 天；小浣熊 access ≈ 3 小时、refresh ≈ 30 天 | 同左 |
| 自动续期 | 小浣熊刷新后写回插件存储；Loomy 无 refresh，过期后再登录一次 | 小浣熊刷新后写回应用文件；Loomy 过期后需重登 |

插件不会把令牌写入日志或设置页响应；设置接口只返回登录来源、账号字段、到期时间和额度。浏览器登录只在模型网关确认凭据可用后才保存，网页登录但拿不到可用网关凭据时会明确报错，不会写入无效状态。

## 已知限制

- 两个上游都是私有接口，可能随客户端更新变化。最易变的是网页登录页的 DOM/存储方式、模型网关的凭据格式，以及小浣熊的 `auth.json` 字段和 refresh 单次使用语义。
- 浏览器登录依赖 Chromium 的 DevTools 协议；如果本机没有 Edge / Chrome / Brave / Chromium，请用 `DSH_LLM_ADAPTERS_BROWSER` 指定可执行文件。Firefox / Safari 不支持。
- Loomy 网页登录可能只签发网页会话，而模型网关要求自己的会话令牌。插件会校验后如实报告「网页里登录成功，但没有拿到可用的模型调用凭据」；这种情况请使用 Loomy 桌面客户端登录态。
- 小浣熊网页端的短信登录需要阿里云滑块验证；浏览器登录时你在官方页面里正常操作即可，插件不代替你解滑块。
- Loomy 在未给出 `finish_reason` 就发送 `[DONE]` 时存在静默截断。插件把这种结束标成 `max-tokens`，避免把半截回答当成正常完成。
- 小浣熊目录里的 `reasoning` 标签描述的是应用侧路由预设，插件不据此提供推理档位。思考文本仍会按上游实际返回透传。
- 小浣熊目录的识图标签已知会错。插件使用实测表（`RACCOON_MEASURED_VISION`），并允许用高级设置覆盖。
- 小浣熊的 `X-Org-Code` 目前按个人版留空；企业版未验证。
- Loomy 模型目录里的倍率从展示名称解析，上游若改格式可能丢失倍率显示；不影响调用。
- 同一个 refresh token 被多个进程同时刷新时，会由上游判定冲突。插件会先重读凭据来源，不盲目重试。
- 登录窗口默认 5 分钟超时；超时或关闭窗口后可以重新发起。
