# dsh-llm-adapters

把 **Loomy（讯飞）** 与 **商汤小浣熊** 接进
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）。

- **浏览器登录，不用装客户端**：设置页点「打开浏览器登录」，在独立窗口里登录官方网页账号，
  插件自动接回。
- **也可复用桌面客户端登录态**：本机已登录 Loomy / 小浣熊时直接读取，不再重复登录。
- **额度可见**：Loomy 显示可用 / 永久 / 每日积分；小浣熊显示剩余积分。
- **两套设置页**：Loomy、商汤小浣熊各自独立的模型开关、上下文窗口与登录卡片。

> 非官方插件。两家都是客户端私有接口，不是官方开放 API；客户端或网页升级后协议可能变化。

## 为什么需要它

两家都没有面向个人用户的开放 API。网页版能登录，但登录后拿到的是网页会话，模型网关并不直接
接受它；桌面客户端则把登录态写在本机文件里。

插件因此提供两条路：

- **浏览器登录**：启动一个使用临时用户目录的 Chromium 窗口，你在官方页面完成登录；插件读取
  该窗口的登录结果，逐条向模型网关校验，只保存真正可用的凭据。
- **复用客户端**：读取 Loomy / 小浣熊自己的登录文件。小浣熊令牌轮换时会把新令牌原子回写，
  避免桌面端下次刷新撞上 `refresh_conflict`。

拿到凭据后，模型调用走两家都兼容的 OpenAI Chat Completions 协议；插件负责把 DSH 的消息、
图片、工具调用与思考流翻译成对应格式。

## 安装

**插件 → 添加插件**，填 `dsh-llm-adapters` 并安装（npm）；也可以从
`github:k1-h2/dsh-llm-adapters` 或本地目录安装。装完按提示**重启 DSH**。

## 登录

**设置 → Loomy** 或 **设置 → 商汤小浣熊** → 点「打开浏览器登录」。弹出的窗口是独立的临时
配置，不影响你日常使用的浏览器；登录成功后窗口会自动关闭，账号、额度与模型列表随即刷新。

浏览器登录需要本机装有 Edge / Chrome / Brave / Chromium。找不到时可用
`DSH_LLM_ADAPTERS_BROWSER` 指定可执行文件。

如果本机已经装了并登录了对应桌面客户端，可以不点浏览器登录，插件会直接复用它的登录态。

Loomy 的网页登录能否直接换取模型网关凭据，取决于上游；拿不到时页面会明确提示，而不是保存
一份无效登录。详见 [常见问题](./FAQ.md)。

## 设置页

- **登录卡**：显示登录方式、账号、到期时间与额度；未登录时可发起浏览器登录，登录中可取消，
  插件账号可「退出登录」（不影响桌面客户端）。
- **模型清单**：来自账号实时目录，逐个启用 / 关闭，并可指定上下文窗口。
- **高级设置**：分组名称、登录态文件路径、强制识图 / 纯文本模型、模型别名、默认输出上限。
- **供应商开关**：在插件管理页关闭某个供应商后，它的设置页、模型分组与 provider 路由一起移除。

再次打开页面时先显示上次快照，账号与模型在后台刷新。

## 用 YAML 配置

设置页之外，也可以直接写进 profile 的 `cordis.patch.yml`：

```yaml
- id: llm-adapters
  name: dsh-llm-adapters
  config:
    loomyEnabled: true
    raccoonEnabled: true
    loomyDisplayName: Loomy
    raccoonDisplayName: 商汤小浣熊
    loomyDisabledModels: []
    raccoonDisabledModels: []
    loomyModelContextWindows: {}
    raccoonModelContextWindows: {}
    defaultMaxTokens: 32000
```

两个 provider 的模型开关、窗口与别名是分开的字段；超时、缓存等运行参数共享。
